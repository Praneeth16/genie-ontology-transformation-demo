# Favorable Gap

Domain: Enterprise Transformation

Subdomain: Operating Performance

Owner: Enterprise Performance Director

Synonyms: target gap, performance gap, variance to target

Description: The direction aware difference between an operating KPI actual value and its target.

## Definition

Favorable Gap makes target variance comparable in meaning across KPIs. A positive gap is favorable. A negative gap is unfavorable.

For a KPI where higher is better, subtract target from actual. For a KPI where lower is better, subtract actual from target. Keep the original KPI unit when reporting the gap.
