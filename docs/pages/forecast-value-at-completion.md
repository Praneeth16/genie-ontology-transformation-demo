# Forecast Value at Completion

Domain: Enterprise Transformation

Subdomain: Value Realization

Owner: Transformation Finance

Synonyms: forecast value, expected benefits, expected value at completion, forecast benefits

Description: The current estimate of the total value an initiative will deliver by completion.

## Definition

Forecast Value at Completion is the current estimate of total value at the end of an initiative. It can be above or below the approved target. It is a forecast and does not count as realized value.

The Transformation Value Office reviews this estimate with the initiative owner and finance. A change in forecast should include a reason, an owner, and a decision when the gap is material.

The governed measure is `Forecast Value at Completion` in `mv_value_realization`.
