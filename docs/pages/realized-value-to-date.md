# Realized Value to Date

Domain: Enterprise Transformation

Subdomain: Value Realization

Owner: Group Finance

Synonyms: realized value, banked value, validated value, actual benefits

Description: The cumulative transformation value that finance has validated by the reporting date.

## Definition

Realized Value to Date is the value that Group Finance has reviewed and accepted by the reporting date. It can include cost, revenue, margin, and working capital value. The portfolio reports all values in US dollars.

Realized value is not the same as planned value or forecast value. Planned value is the amount expected by the reporting date. Forecast value is the amount expected when the initiative finishes.

## Calculation

The governed measure is `Realized Value to Date` in `mv_value_realization`.
