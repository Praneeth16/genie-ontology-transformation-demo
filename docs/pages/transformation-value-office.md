# Transformation Value Office

Domain: Enterprise Transformation

Owner: Chief Transformation Officer

Synonyms: TVO, transformation office, value office, enterprise transformation office

Description: The group that governs the Northstar transformation portfolio, resolves decisions, and reports value and delivery to the executive committee.

## Definition

The Transformation Value Office sets the reporting method for the Northstar portfolio. Finance owns value validation. Initiative owners report delivery progress, risks, and milestones. The executive committee decides issues that teams cannot resolve within their authority.

The office reports approved target value, planned value to date, realized value to date, forecast value at completion, approved investment, delivery health, critical risks, milestones, and operating KPI attainment.

## Decision rule

The office asks leaders to intervene when an initiative is red, has an overdue critical risk, has an overdue milestone, or has a material forecast value shortfall.
