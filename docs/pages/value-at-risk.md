# Value at Risk

Domain: Enterprise Transformation

Subdomain: Value Realization

Owner: Transformation Finance

Synonyms: forecast shortfall, target value at risk, value shortfall

Description: The positive gap between approved target value and forecast value at completion.

## Definition

Value at Risk shows how much approved portfolio value the current forecast may not deliver. It supports intervention and does not claim that value has already been lost.

If the forecast is above the target, Value at Risk is zero. Gains above target do not offset shortfalls in another initiative when the measure is calculated by initiative and then summed.

## Calculation

For each initiative, subtract Forecast Value at Completion from Target Value. Use zero when the result is negative. Add the initiative results for a portfolio total.

The governed measure is `Value at Risk` in `mv_value_realization`.
